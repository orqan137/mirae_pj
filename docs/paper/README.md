운영 검색 코퍼스에는 자동으로 합치지 않는다.

- [`연금/`](연금/README.md): 연금·은퇴설계 논문, 한국 제도·통계, 설계 도출
- [`에이전트/`](에이전트/README.md): Agent/RAG/금융 QA 논문, 평가셋, 설계 도출
- [`research/`](research/README.md): 기존 Agent/RAG 기초 연구 카탈로그
- [`domain/`](domain/README.md): 기존 법령·통계·리포트·뉴스 출처 카탈로그

외부 자료는 출처, 기준일, 검토일과 적용 가능성을 기록하고
[`domain/source-governance.md`](domain/source-governance.md)의 승인 절차를 따른다.
