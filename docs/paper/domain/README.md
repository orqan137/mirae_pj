# Pension and finance domain references

이 디렉터리는 연금·금융 관련 외부 자료의 카탈로그다. 주최 측 제공 자료와 달리 외부 자료는
자동으로 모델 Context에 들어가지 않는다.

## 분류

- [`official-sources.md`](official-sources.md): 법령, 세무, 감독, 공공 통계, 공식 공시
- [`research-and-reports.md`](research-and-reports.md): 공공·학술·산업 연구 보고서
- [`news-watchlist.md`](news-watchlist.md): 제도 변경과 시장 동향을 추적하는 뉴스·보도자료
- [`source-governance.md`](source-governance.md): 수집, 검토, 승격, 폐기 규칙

## 중요 원칙

1. 대회 답변은 주최 측 자료를 우선한다.
2. 외부 자료는 공식 허용 여부를 확인하기 전까지 `catalog-only`다.
3. 세율·한도·연령·수익률·수수료는 발행일이 아니라 적용 기준일을 함께 기록한다.
4. 뉴스는 사실 확정 근거가 아니라 변경 탐지 신호로 사용한다.
5. 법령은 기사나 해설이 아니라 국가법령정보센터의 현행 조문으로 최종 확인한다.
6. 상품 정보는 광고·기사보다 투자설명서, 약관, 감독기관 공시를 우선한다.
