# 연금·금융 뉴스·동향 watchlist

뉴스는 변경 탐지용이다. 기사 수치를 곧바로 답변 근거로 사용하지 않고, 연결된 법령·공시·기관
보도자료의 원문을 확인한다.

## 갱신 절차

1. 뉴스·보도자료에서 변경 신호를 발견한다.
2. 법령, 감독 공시, 공식 통계 원문을 찾는다.
3. 발표일, 시행일, 통계 기준일을 각각 기록한다.
4. 기존 주최 측 자료와 충돌 여부를 표시한다.
5. 대회 외부자료 사용 허용 범위를 확인한다.
6. 승인되면 새 버전의 파생 코퍼스와 회귀 정답을 만든다.
7. 제출 마감 이후에는 코드·지식 자료를 갱신하지 않는다.

## 기사 등록 규칙

- 제목, 언론사, 기사 URL, 게시시각, 원출처를 기록한다.
- 기사에 인용된 수치의 원표와 정의를 확인한다.
- 광고·협찬·회사 홍보자료는 `marketing`으로 표시한다.
- 단기 수익률 순위는 제도, 원리금보장 여부, 적립금 규모, 기간이 다르면 직접 비교하지 않는다.
- 링크가 사라져도 사실을 재현할 수 있도록 공식 원문 ID를 함께 기록한다.
